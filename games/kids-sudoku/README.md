# 小小数独 · 一年级趣味数独

一个单文件网页小游戏，直接用浏览器打开 `index.html` 就能玩（手机、平板、电脑都可以）。

## 玩法
- 点一个空格子，再点下面的图案放进去。
- 每一横行、每一竖列、每个颜色小方块里，每个图案只能出现一次。

## 特点
- **三种难度**：简单（4×4，5 个空）、进阶（4×4，9 个空）、挑战（6×6，16 个空）。每局随机生成，且保证只有唯一答案。
- **三种图案**：小动物、水果、数字，不认识数字的小朋友也能玩。
- **温和纠错**：放错时会晃一晃，并指出“这一横行里已经有小猫啦”，然后自动撤回。
- **提示按钮**：自动挑最容易推理的格子给出答案，并说明理由。
- **鼓励反馈**：音效 + 中文语音夸奖（可关闭），完成后按错误次数得 1～3 颗星，并累计奖牌。
- 键盘支持：方向键移动，数字键 1～6 填入。
