# Subtitle Mask —— 一键遮挡视频字幕的 Chrome 插件

在 bilibili.com / youtube.com 看视频（如美剧）时，用黑条遮住画面下方的字幕。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `subtitle-mask` 文件夹
4. 建议点工具栏的拼图图标，把 Subtitle Mask 固定到工具栏

## 使用

- **开/关遮挡**：点工具栏上的插件图标，或按快捷键 `Alt+S`（图标上显示 `ON` 表示已开启）
- **调整位置**：鼠标按住黑条上下拖动
- **调整高度**：鼠标在黑条上滚动滚轮
- 支持网页全屏 / 全屏，位置和高度会自动记住

快捷键可在 `chrome://extensions/shortcuts` 修改。
