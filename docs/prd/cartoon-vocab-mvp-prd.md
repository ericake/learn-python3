| 项目 | 内容 |
| --- | --- |
| 产品暂定名 | 动画词卡（Cartoon Word Pal） |
| 文档版本 | v0.1（MVP） |

| 更新日期 | 2026-10-12 |
| 目标平台 | iPad / 平板浏览器优先（H5 / PWA），兼容手机竖屏 |

---

## 1. 背景与问题

### 1.1 需求场景
一个 6 岁的孩子每天固定看一集英文动画片（如 *Peppa Pig*、*Bluey*、*Paw Patrol*）。家长希望：

- **看之前（预习）**：先认识这一集里的关键词和短语，看动画时能“听得出来”，提升理解和兴趣；
- **看之后（复习）**：把刚听到的词和短语再巩固一遍，并在之后几天里自动回顾。

### 1.2 用户限制
- 孩子 **不具备英文阅读能力**（也基本不认识中文字），所有孩子端交互必须 **零文字依赖**：靠声音、图片、动画、音效完成。
- 注意力时长短：单次学习 **5～8 分钟**为宜。
- 精细操作能力有限：只能稳定完成“点一下”，不适合拖拽、输入。

### 1.3 现有方案的问题
| 方案 | 问题 |
| --- | --- |
| 通用单词 App | 词表与孩子正在看的动画无关，缺少语境，孩子没兴趣 |
| 家长自己讲解 | 家长英语水平/时间不一，难以每天坚持；不好找配图 |
| 直接重复看动画 | 关键词一闪而过，孩子听不出来，“看热闹”多于“学语言” |

### 1.4 解决思路
参考 **Rosetta Stone 的“听音识图”沉浸式模式**（不翻译、不读字，用“声音 ↔ 图片”的直接映射建立意义），由家长输入当集动画台词，系统自动提取重点词/短语并生成配图与发音，形成每集专属的预习、复习小课。

---

## 2. 目标与非目标

### 2.1 产品目标（MVP）
1. 家长 **3 分钟内** 完成一集的内容准备（粘贴台词 → 审核词表 → 生成课程）。
2. 孩子 **独立完成**（无需家长陪读）一节 5～8 分钟的预习或复习。
3. 孩子对当集重点词的 **听音识图正确率**：复习后 ≥ 80%。
4. 跑通“每天 1 集”的日常习惯闭环，验证留存。

### 2.2 非目标（MVP 不做）
- 不做视频播放、不嵌入/下载动画片资源（版权风险）。
- 不做自动语音识别抓取台词（ASR）、不做视频字幕自动抓取。
- 不做跟读打分 / 发音评测（列入 V2）。
- 不做阅读、拼写、书写类练习。
- 不做社交、排行榜、内购、广告。
- 不做多孩子账号（MVP 单家庭单孩子）。

## 3. 用户角色

| 角色 | 描述 | 核心诉求 | 使用端 |
| --- | --- | --- | --- |
| 孩子（主要学习者） | 6 岁，能听懂简单英文指令或完全零基础，不识字 | 好玩、看得懂、能自己点、做对有奖励 | 孩子端（全图形、全语音） |
| 家长（内容管理者） | 能读英文台词，时间碎片化 | 准备内容快、词选得准、看得到效果 | 家长端（有文字，带家长锁） |

## 4. 核心用户流程

```
[家长] 新建剧集 → 粘贴/上传台词 → 系统提取重点词&短语 → 家长审核/增删 → 生成图片与音频 → 课程就绪
                                                                                       │
[孩子] ────────────── 预习（看动画前，5~8 分钟）◄──────────────────────────────────────┘
                              │
                        看动画（App 外）
                              │
                       复习（看动画后，5~8 分钟）
                              │
               间隔复习（第 1 / 3 / 7 天自动混入当日课程）
                              │
[家长] ◄──────────── 学习报告（完成情况、正确率、薄弱词）
```

### 4.1 典型一天
1. 前一晚或当天，家长在家长端粘贴 *Peppa Pig S1E1 Muddy Puddles* 的台词，确认 6 个词 + 2 个短语，点击“生成”。
2. 晚饭后孩子打开 App，首页只有一个大大的 **“看前”按钮（眼镜/望远镜图标）**，点开完成预习。
3. 孩子看动画。
4. 看完后首页亮起 **“看后”按钮（星星/礼物图标）**，完成复习，获得贴纸。
5. 家长在报告页看到：“puddle 3/3 正确，jump 第一次选错”。

## 5. 功能需求

> 优先级：P0 = MVP 必须；P1 = MVP 尽量做；P2 = 后续版本。

### 5.1 家长端

#### F1 剧集管理（P0）
- 新建剧集：字段 = 动画名称（可选自下拉历史记录）、季/集（选填）、标题（选填）、计划观看日期（默认今天）。
- 剧集列表：显示状态（草稿 / 生成中 / 已就绪 / 已预习 / 已复习）。
- 支持编辑、删除、复制剧集。

#### F2 台词输入（P0）
- **输入方式**
  - P0：多行文本框粘贴完整台词（上限 20,000 字符，约一集 5～25 分钟动画）。
  - P1：上传 `.txt` / `.srt` / `.vtt` 字幕文件。
- **自动清洗**
  - 去除时间轴（`00:01:02,345 --> ...`）、序号、HTML/样式标签、`[Music]` `(laughs)` 等音效标注。
  - 识别说话人前缀（如 `PEPPA:`、`Narrator:`），保留为元数据，不参与词汇提取。
  - 合并断行，按句切分，去重连续重复行。
- **校验**：少于 3 句或非英文为主时提示“台词内容过少/似乎不是英文”。

#### F3 重点词与短语提取（P0）
系统基于台词自动生成候选清单，家长审核后定稿。

**提取规则**
| 维度 | 规则 |
| --- | --- |
| 数量 | 默认每集 **6～8 个词 + 2～3 个短语**，总数 ≤ 10（家长可调 4～12） |
| 可视化优先 | 优先选择 **可画出来** 的内容：具体名词（puddle, boots）、动作动词（jump, splash）、可感知形容词（muddy, big, wet）、方位/颜色/数字等 |
| 降权/排除 | 功能词（the, is, of）、抽象词（idea, maybe）、难以图示的词；人名/角色名默认排除（可选“保留角色名”作为热身） |
| 情节重要度 | 在台词中出现频次高、或与剧情核心相关的词加权 |
| 难度适配 | 结合儿童高频词表（如 Dolch / Fry 前 300、CEFR Pre-A1/A1）评估，太简单的已掌握词降权（读取孩子历史掌握记录） |
| 短语 | 选取 2～4 词的高频语块/固定表达，且能用一个场景画面表达：`jump up and down`, `go to bed`, `I'm hungry`, `Let's go!`, `Look at me!` |
| 词形还原 | 统一为原形（jumping → jump），但保留台词中原始形态用于“原句”音频 |
| 去重 | 与孩子已掌握词（见 F9）重复时标注“已学过”，默认不选 |

**每个条目输出字段**
- `text`：词/短语（原形）
- `type`：noun / verb / adj / phrase / other
- `meaning_zh`：中文释义（仅家长端显示，帮助家长审核）
- `source_sentence`：台词中的原句（1 句，优先短句）
- `image_prompt`：配图描述（单一主体、无文字、儿童插画风）
- `visualizability`：可视化评分 1～5
- `reason`：入选理由（如“出现 7 次，剧情核心”）

**家长审核（P0）**
- 候选列表以卡片展示：词 / 中文释义 / 原句 / 入选理由，每项可 **勾选/取消**。
- 可手动 **新增** 词或短语（输入文本，系统自动补全其余字段）。
- 可编辑原句、释义、配图描述。
- 额外展示 5～10 个“备选词”，一键替换。

#### F4 学习素材生成（P0）
| 素材 | 要求 |
| --- | --- |
| 配图 | 每个条目 1 张主图；风格统一（扁平卡通、高对比、纯色/简单背景、**画面内无任何文字**）；单一主体、居中；动词需表现动作（“小猪正在跳”）；短语用简单场景图。来源：AI 文生图为主，常见词优先使用内置图库以保证质量与速度 |
| 干扰图 | 不单独生成，从本集其他条目 + 内置图库同类词中选取（规则见 F6） |
| 单词音频 | TTS，儿童友好音色（美/英音可选，默认与动画口音一致，如 Peppa 用英音）；正常语速 + 慢速（0.75x）两版 |
| 原句音频 | TTS 朗读 `source_sentence`，用于复习时语境再现 |
| 指令语音 | 固定预录音频（不依赖 TTS），如 “Listen!”、“Where is…?”、“Great job!”，以及可选中文提示音轨 |

- 家长可对任一图片点击 **“换一张”**（重新生成，最多 3 次）或从相册上传替换。
- 生成过程显示进度；单集总生成时长目标 **≤ 60 秒**。
- 生成完成后素材 **预缓存** 到设备，孩子端离线可用。

#### F5 学习报告（P0 简版）
- 每集：预习/复习是否完成、用时、每个词的首次选择正确率。
- 词汇总览：已掌握 / 学习中 / 薄弱 三档，薄弱词可一键加入“明日复习”。
- 连续学习天数。

#### F6 家长设置（P1）
- 每节时长偏好（短 3～5 分钟 / 标准 5～8 分钟）。
- 口音（美音 / 英音）、是否开启中文语音提示（给零基础孩子过渡）。
- 每日学习提醒时间。
- 家长锁：进入家长端需完成简单算术题或长按 3 秒（防孩子误入）。

### 5.2 孩子端

#### 孩子端交互总原则（P0，全局适用）
1. **零文字**：孩子端界面不出现任何文字（含按钮），全部用图标 + 语音 + 动画表达。
2. **声音先行**：每一屏进入时自动播放语音；任何图片/喇叭图标都可点击重听。
3. **大目标、单任务**：可点击区域 ≥ 120×120pt，一屏只做一件事，最多 4 个选项。
4. **无惩罚**：答错不扣分、不出现红叉和刺耳音效；以温和音效 + 高亮正确答案 + 重听来纠正。
5. **固定节奏**：每题流程固定（听 → 选 → 反馈），帮助孩子形成预期。
6. **随时退出**：左上角“回家”图标（长按 2 秒生效，防误触），进度自动保存。

#### F7 预习模式「看前」（P0）
目标：在看动画前建立“声音 ↔ 画面”的初步映射。时长 5～8 分钟。

| 阶段 | 形式 | 说明 |
| --- | --- | --- |
| ① 引子 | 展示动画名对应的封面色/角色剪影 + 语音 “Today we will watch …! Let's learn some words!” | 建立期待（角色剪影为通用卡通形象，不使用版权角色图） |
| ② 认识（Introduce） | 一次一张大图 + 自动播放读音 2 遍（正常 + 慢速）；孩子点图可重听；点“下一个”箭头继续 | 每个条目约 10 秒，共 6～10 个 |
| ③ 二选一（Recognize-2） | 播放 “Where is **puddle**?”，显示 2 张图 | 低难度，快速建立信心 |
| ④ 四选一（Recognize-4） | 播放读音，显示 4 张图（Rosetta Stone 经典听音识图） | 每个条目至少考 1 次，顺序打乱 |
| ⑤ 短语场景 | 播放短语音频（如 “jump up and down”），从 2～3 张场景图中选 | 仅针对短语条目 |
| ⑥ 结束 | 动画庆祝 + 贴纸 + 语音 “Now let's watch! Listen for these words!” | 引导去看动画、带着任务去听 |

#### F8 复习模式「看后」（P0）
目标：结合动画语境巩固，提高辨识速度。时长 5～8 分钟。在当集预习完成后解锁（家长可在设置中关闭此限制）。

| 阶段 | 形式 | 说明 |
| --- | --- | --- |
| ① 热身回顾 | 快速闪现本集所有图片 + 读音（每个 3 秒） | 唤醒记忆 |
| ② 四选一听音识图 | 同预习，但 **不再先展示答案**，干扰项更相近 | 每词 1 次 |
| ③ 原句语境（Sentence → Picture） | 播放台词原句（“Peppa loves jumping in **muddy puddles**.”），关键词读音加重，孩子选出对应图 | 把词还原回动画语境 |
| ④ 短语听辨 | 播放短语，选场景图；或播放场景图下的两段音频，选哪个对（P1） | 强化语块 |
| ⑤ 错题回炉 | 本节答错的条目，以“二选一”再出现一次 | 保证以成功结束 |
| ⑥ 结束奖励 | 贴纸 + 收集册进度动画 | 激励 |

#### F9 间隔复习（P0 简版）
- 每个条目维护掌握状态：`new → learning → mastered`。
  - 首次作答正确记 +1，答错记 0；连续 3 次（跨不同天）首次即正确 → `mastered`。
- 复习调度：条目在学习后的 **第 1、3、7 天** 自动进入“今日复习”。
- 当天有新剧集时，在“看后”复习的第②阶段混入 **最多 3 个** 到期旧词；没有新剧集时，首页显示“小复习”按钮（3 分钟，仅四选一）。
- 薄弱词（错误 ≥ 2 次）优先调度。

#### F10 题型与干扰项规则（P0）
**题型定义**

| 题型 ID | 名称 | 刺激 | 选项 | 适用 |
| --- | --- | --- | --- | --- |
| Q1 | 认识卡 | 图 + 读音 | 无（点击继续） | 预习 |
| Q2 | 听音二选一 | 读音 / "Where is X?" | 2 图 | 预习、错题回炉 |
| Q3 | 听音四选一 | 读音 | 4 图 | 预习、复习、间隔复习 |
| Q4 | 原句选图 | 台词原句音频 | 3～4 图 | 复习 |
| Q5 | 短语场景 | 短语音频 | 2～3 场景图 | 预习、复习 |

**干扰项选择**
- 优先从本集其他条目中选；不足时从内置图库补充。
- 干扰项与正确答案 **视觉上可区分**，但复习阶段可选同类别（如都是动物）以提升难度。
- 避免发音过于相近的组合出现在预习阶段（如 cat / cap）。
- 同一题内选项位置随机，正确答案不得连续 3 题出现在同一位置。

#### F11 反馈与激励（P0）
| 情况 | 反馈 |
| --- | --- |
| 答对 | 选中图片放大弹跳 + 欢快音效 + 随机鼓励语音（“Great!”、“Well done!”、“You got it!”）+ 再读一遍该词 |
| 答错 | 被选图片轻轻晃动 + 柔和提示音；正确图片发光并重读该词；同题允许再选一次，第二次仍错则直接展示答案并进入下一题 |
| 无操作 10 秒 | 自动重播题目音频；30 秒无操作，正确选项轻微闪动提示 |
| 完成一节 | 获得 1 张贴纸（主题随动画变化），进入贴纸收集册 |
| 连续 7 天 | 解锁特别贴纸/角色装扮 |

#### F12 首页（P0）
- 极简：今日剧集的大卡片（颜色区分）+ 两个大按钮：**看前（预习）**、**看后（复习）**，未解锁的按钮半透明并带“锁”图标。
- 下方：贴纸册入口、“小复习”入口（有到期词时出现）。
- 右上角：家长入口（家长锁保护）。
- 当天无剧集时：显示“小复习”或可爱的“等待中”动画，并播放 “Ask Mommy or Daddy for a new show!”

## 6. 内容生成方案（建议）

### 6.1 处理流水线
```
台词原文
  → 清洗与分句（规则）
  → 分词 / 词性标注 / 词形还原（spaCy 等 NLP 工具）
  → 候选生成：词频统计 + 语块（n-gram）抽取
  → 打分：频次 × 可视化评分 × 难度适配 × 情节重要度 − 已掌握惩罚
  → LLM 精选与补全（选出最终条目，生成中文释义 / 原句 / image_prompt / reason）
  → 家长审核
  → 配图（图库命中 → 直接用；否则文生图）+ TTS 音频
  → 课程编排（按 F7/F8/F10 规则生成题目序列）
```

### 6.2 LLM 提取 Prompt 要点（示意）
```
你是一名儿童英语启蒙老师。孩子 6 岁，不识字，通过“听音识图”学习。
以下是英文动画《{show}》一集的台词。请选出 {n_words} 个重点单词和 {n_phrases} 个重点短语，要求：
1. 必须能用一张简单图片清楚表达（具体名词、动作、可感知的形容词、简单场景）；
2. 在台词中出现、且对理解剧情有帮助，出现次数多的优先；
3. 排除功能词、抽象词、人名；排除孩子已掌握词：{mastered_words}；
4. 单词用原形；短语 2~4 个词，为口语中常用表达；
5. 为每项给出：text, type, meaning_zh, source_sentence（台词原句，选最短最清楚的一句）,
   image_prompt（英文，儿童扁平插画风，单一主体，纯色背景，画面中不能有文字）, visualizability(1-5), reason。
仅输出 JSON。
台词：
{transcript}
```

### 6.3 输出示例
输入（节选，*Peppa Pig – Muddy Puddles*）：
```
It is raining today. So, Peppa and George cannot play outside.
Peppa loves jumping up and down in muddy puddles.
If you jump in muddy puddles, you must wear your boots.
George likes to jump in muddy puddles too.
```
输出（节选）：
```json
{
  "words": [
    {"text": "rain", "type": "verb", "meaning_zh": "下雨", "source_sentence": "It is raining today.",
     "image_prompt": "rain falling from a grey cloud, flat cartoon style, plain light background, no text",
```

## 7. 数据模型（MVP）

| 实体 | 关键字段 |
| --- | --- |
| Child | id, nickname, avatar, accent_pref, created_at |
| Episode | id, child_id, show_name, season, episode, title, transcript_raw, transcript_clean, status, planned_date |
| VocabItem（全局词条） | id, text, type, default_image_id, audio_normal_url, audio_slow_url |
| EpisodeItem | id, episode_id, vocab_item_id, source_sentence, sentence_audio_url, image_id, meaning_zh, order |
| Image | id, url, source(library/ai/upload), prompt |
| Session | id, child_id, episode_id, mode(preview/review/spaced), started_at, finished_at |
| Attempt | id, session_id, vocab_item_id, question_type, options[], chosen, is_correct, is_first_try, latency_ms |
| Mastery | child_id, vocab_item_id, status, correct_streak, last_seen_at, next_due_at, wrong_count |

> 同一个词在不同剧集中复用全局 VocabItem 的图片与音频，降低生成成本并保证一致性。

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 儿童隐私与安全 | 遵循《儿童个人信息网络保护规定》/ COPPA：不采集孩子真实姓名、照片、语音；仅家长账号注册；无广告、无外链、无社交；数据可一键导出/删除 |
| 内容安全 | AI 生成图片需经过安全过滤（暴力、恐怖、不适宜儿童内容）；家长审核兜底 |
| 版权 | 不存储/展示动画视频与官方角色图片；台词仅用于该家庭自用学习，不公开分享 |
| 性能 | 孩子端题目切换 ≤ 300ms；音频点击到出声 ≤ 200ms；单集素材生成 ≤ 60s |
| 离线 | 已生成课程可离线完成；作答记录联网后同步 |
| 可用性 | 平板横屏优先；字体/图标在 1 米观看距离清晰；音量适中且有统一音量归一化 |
| 护眼 | 单次连续使用超过 15 分钟，弹出休息动画（P1） |
| 可访问性 | 色彩不作为唯一信息载体（对错同时有动效区分） |

## 11. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| AI 配图不准确或风格不统一 | 孩子形成错误映射 | 高频词使用人工精修图库；统一风格 prompt 模板；家长“换一张/上传” |
| 抽象词/短语难以图示 | 题目无法作答 | 提取阶段按可视化评分过滤；短语限定为可场景化表达 |
| 孩子靠“排除法/位置”猜答案 | 正确率虚高 | 选项位置随机；干扰项来自同集；统计首选正确率与反应时长 |
| TTS 发音与动画口音不一致 | 孩子在动画中认不出 | 支持英/美音；默认按动画匹配；关键词提供慢速版 |
| 家长获取完整台词困难 | 无法生成内容 | 支持粘贴任意片段（≥ 3 句即可）；P1 支持字幕文件；V2 考虑预置热门动画词包 |
| 版权问题 | 法律风险 | 不存储视频、不使用官方角色图；台词仅家庭私用 |
| 孩子沉迷或反感 | 违背初衷 | 单节时长上限；每天任务明确有终点；无无限刷题 |

## 附录 A：孩子端单题交互时序（Q3 听音四选一）

```
进入题目 ─► 4 张图依次淡入（0.6s）─► 自动播放 "Where is … puddle?"（重读关键词）
   │
   ├─ 孩子点喇叭 / 任意时刻 ─► 重播音频
   │
   ├─ 点中正确图 ─► 放大弹跳 + 鼓励语音 + 再读 "puddle" ─► 1.2s 后自动下一题
   │
   └─ 点中错误图 ─► 轻晃 + 柔和提示音 ─► 重播音频，允许再选
            └─ 第二次仍错 ─► 正确图发光 + 读音 ×2 ─► 下一题（该词进入错题回炉）
```

## 附录 B：术语表

| 术语 | 说明 |
